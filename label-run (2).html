    Output

    Load a spreadsheet or add a label by hand to begin.

    Westinghouse WHTP203e: use the PDF. It runs at 203 dpi over USB or Ethernet with its own Windows, macOS or Linux driver, so the PDF is the file it understands. It is not a Zebra and is not documented to accept ZPL, so the ZPL file is not for it.
    Sending the file to the printer

    PDF — any printer, including the Westinghouse

    Install the printer's driver, open the PDF, and print. Set the paper size to your label size and scaling to 100% or Actual Size — never Fit to Page. Run the printer's calibration once after loading a new roll so it learns the gap between labels.

    ZPL over the network (Zebra and ZPL-compatible only)

    nc 192.168.1.50 9100 < labels.zpl

    ZPL over USB (Zebra and ZPL-compatible only)

    lp -o raw -d ZebraPrinter labels.zpl
    cmd /c copy /b labels.zpl \\localhost\ZebraPrinter

    A browser cannot open a raw network socket, so ZPL has to be downloaded and sent by one of the above. The PDF route needs none of this.
